    先看每月实际消耗的流量，再对照表格里的额度，不要倒过来选。

  2. 第二步 数清要联网的设备

    手机、平板、笔记本分开算；同时在线的数量是硬性上限。

  3. 第三步 比对线路类型

    普通节点池、全节点、专线，三档的差别写在表格第二列起。

  4. 第四步 决定按月还是按年

    年付单价换算下来是十个月的钱，但要一次性付清。

02 / 客户端

你会用到哪些客户端

客户端是通用软件，NTTSS 不单独提供下载镜像。下表只说明每类系统上常见的选择与须知，不构成对任何软件的背书；版本与获取方式请以软件自身的官方渠道为准。

桌面端

macOS 与 Windows

桌面端使用图形化客户端导入订阅信息即可，通常只需粘贴一次订阅地址。建议在导入后<事业>手动确认一次规则模式，避免把本地网络的访问也一起改道。客户端版本自行升级，本页不提供安装包地址。

移动端

iOS 与 Android

iOS 上这类工具通常以系统网络配置的方式工作，首次启用需要允许相应权限，退出时记得关闭。Android 端选择较多，建议只用仍在维护的版本。移动设备计入同时在线上限，一台手机也算一台。

路由器

家庭网关接入

团队版涉及定制路由时，建议由懂网络配置的人操作，先在局域网内单点验证，再全屋下发。路由器接入后，下游设备通常共用一条连接，请据此重新估算设备数是否够用。

账号

多设备共用的边界

同一账号在不同设备上登录是允许的，但同时在线的数量不能超过所选档位。当出现挤占时，通常是旧设备没有正常退出，先把不用的设备下线，再排查其他原因。

03 / 使用

从选档到日常使用的四步

按顺序做，任何一步卡住就先停下核对，不要跳到下一步。

  1. 估算月流量 回看最近一个月的实际用量，加上两成余量，再对到 100GB、300GB、1000GB 中最近的一档。
  2. 确定设备与线路 把常年同时在线的设备列出来；有游戏或高清流媒体需求，就把线路类型的权重提到价格之前。
  3. 选择计费周期 确定会连续用满一年再选年付；不确定就先按月付，后续再调整，避免一次付清后闲置。
  4. 导入并逐项验证 在主力设备上先导入一次，确认能正常访问，再依次配置其余设备，每配一台就检查在线数是否超限。

04 / 常见问题

十个问题，逐条回答

下面这些问题按提问频率排列，左栏关于套餐与计费，右栏关于使用与账号。

Q三档套餐最核心的差别是什么？

流量额度、同时在线设备数、线路类型三点同时变化：100GB／3 台／普通节点池，300GB／5 台／全节点与专线，1000GB／20 台／高带宽节点。选档时以这三项为准，价格差异是结果而不是依据。

Q年付真的比月付划算吗？

按页面价格换算，年付总额相当于十个月的月付金额，其余两个月相当于赠送额度。前提是你确实会连续使用满一年；中途停用不会按剩余月份退回已付费用。

Q所选档位可以中途更换吗？

可以在新计费周期开始时更换档位，页面上不设自动升降。更换后，流量与设备上限按新档位执行，原周期的剩余流量不叠加到新周期。

Q流量用完了会怎样？

当月额度用尽后，连接将不再提供正常速率，需等到下一个计费周期重置。是否提供额外加量，请以购买时页面实际显示为准，本页不做额外承诺。

Q设备数怎么计算？

以同一时刻保持连接的设备数为准，手机、平板、电脑、路由器都各算一台。已退出但未关闭客户端的设备可能仍被判定在线，建议先彻底退出再进行排查。

Q订阅信息要怎么导入客户端？

在客户端中选择从地址导入，粘贴订阅链接后保存即可；不同客户端的菜单名称略有差异。导入属于本地配置操作，导入过程本身不产生额外流量消耗。

Q为什么某些流媒体仍打不开？

基础版只包含基础流媒体解锁，冷门平台可能不在范围内。旗舰版与团队版提供全节点原生解锁，但平台侧的区域策略会独立变化，能否播放最终由平台判定。

Q团队版适合什么样的组织？

适合需要统一管理较多设备、并要求固定带宽表现的团队。团队版包含企业定制路由与专属客户经理，具体配置内容会在实际对接时由双方确认，本页不预设细节。

Q遇到问题从哪里获得支持？

基础版通过工单提交，旗舰版使用 7×24 优先工单通道，团队版另有专属客户经理对接。提交时请写明设备系统、客户端名称与现象出现的时间，能显著缩短排查轮次。

Q我该先试用还是先订阅？

本页不提供试用承诺。稳妥的做法是先选最低的月付档位，用一周时间观察实际用量与线路表现，再决定是否升级档位或改为年付，避免一次性投入后发现不匹配。
